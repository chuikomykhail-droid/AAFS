## Помічені помилки ШІ

1. **Перша спроба `&&` у PowerShell.** Агент використав `&&` як роздільник команд — це bash-синтаксис, який не працює у старих версіях PowerShell. Виправлено на `;`.
2. **Невірний маппінг колонок у v1 EDA-скрипту.** Скрипт намагався знайти колонки за евристиками (`location`, `location_type`), але реальні колонки мали прямі імена (`oblast`, `raion`, `hromada`, `level`). Результат — порожні секції аналізу. Виправлено у v2 після вивчення реальних даних.
3. **Кодування Windows cp1252.** Кирилиця у `print()` падала з `UnicodeEncodeError`. Виправлено через `$env:PYTHONIOENCODING='utf-8'`.

## Формат сирих логів

Файли `raw/transcript*.jsonl` — JSON Lines, де кожен рядок — один крок (step) діалогу. Ключові поля:
- `step_index` — індекс кроку
- `source` — `USER_EXPLICIT`, `MODEL`, `SYSTEM`
- `type` — `USER_INPUT`, `PLANNER_RESPONSE`, `GENERIC`, `SYSTEM_MESSAGE`, `ERROR_MESSAGE`
- `content` — текстовий зміст
- `thinking` — ланцюжок думок моделі (CoT)
- `tool_calls` — масив викликів інструментів
- `created_at` — ISO 8601 таймстемп

Чутливі токени перевірені — жодних не знайдено.
