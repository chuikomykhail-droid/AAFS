### S7-2. Проверка утечки не проверяет код бэктеста
- **Серьёзность:** существенно (формулировка гарантии в README и D18; на результаты не влияет).
- **Уверенность:** проверено по коду и на данных.
- **Где:**
  - `src/alerts/leakage.py:80` — `train = data[(data['t'] <= cut - h) …]`;
  - `src/alerts/backtest.py:37` — `train = (t <= day - h)`;
  - `src/alerts/tuning.py:23`;
  - `DECISIONS.md:468`, `README.md:77-83`.

**Что не так:**
- `leakage.check` строит обучающие строки собственной копией правила `t ≤ cut − h` (`forecasts_at`). `backtest.walk_forward` и `tuning.tune` она не вызывает.
- Ни один тест не импортирует `alerts.backtest`: в `tests/` слово `backtest` встречается только как ключ конфига.
- D18 пишет, что тест «падает, если… обучаться на `t ≤ cut`». Это верно для копии в `leakage.py`. Если в `walk_forward` заменить условие на `t <= day`, не упадёт ни тест, ни проверка в `run_all.py`.

**Доказательство:**
- Сейчас код верен, и это подтверждено численно (`bridge.py`). `forecasts_at` на реальных данных в срезе 2026-08-10 даёт 568 326 обучающих строк, как в `leakage_check.json`. Прогнозы 89 строк совпали с прогнозами бэктеста из parquet бит в бит для всех пяти моделей.
- Для сравнения — подмены, которые тесты ловят (`mutations.py`):
  - M1 — счётчики `starts_*` сдвинуты на час в будущее: падают и `test_leakage`, и `test_knowledge`;
  - M4 — `country_starts_60m` считает начала в `(t, t+60m]`: падают оба.
- Так что признаковая часть проверки работает, а слабое место только одно — отбор строк в бэктесте.

**Последствие:** гарантия «прогнозы бэктеста не видят будущего» опирается на чтение кода, а не на тест. Регрессия в `walk_forward` осталась бы незамеченной.

**Что сделать (30–40 мин):**
- в `forecasts_at` вызывать `backtest.walk_forward(data, h, [cut.floor('D')], make)` и брать из результата строки с `t = cut`; либо добавить синтетический тест на `walk_forward` с подменой;
- в README и D18 написать, что именно проверено.

Полный `run_all.py` не нужен: достаточно `pytest` и одного прогона проверки утечки. Справочные цифры не меняются.
