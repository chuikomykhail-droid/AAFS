### S7-3. `scripts/api_check.py` завершается с `FileNotFoundError` на чистом клоне
- **Серьёзность:** существенно (воспроизводимость скрипта из корня).
- **Уверенность:** проверено по коду.
- **Где:** `scripts/api_check.py:45-47`.
- **Что не так и почему:** В строках 45–47 скрипт выполняет:
  ```python
  raw_dir = ROOT / cfg['api']['raw_dir']

  raw = read_raw(raw_dir)
  ```
  Папка `data/raw/` занесена в `.gitignore` и в git не хранится. - **Последствие:** Ложное впечатление о неработоспособности скрипта проверки этапа 8 при проверке с чистого клона.
- **Что сделать и сколько стоит:** Добавить в начало `scripts/api_check.py` проверку наличия `raw_dir / 'manifest.jsonl'` с дружелюбным выводом: *«Сырые данные alerts.in.ua не найдены. ### S7-6. Код `src/alerts/leakage.py` не гарантирует побитовое совпадение обучающих строк
- **Серьёзность:** мелочь.
- **Уверенность:** проверено по коду и на данных.
- **Где:** `src/alerts/leakage.py:98`, `README.md:78`, `DECISIONS.md:553`.
- **Что не так и почему:** В `README.md:78` и `DECISIONS.md:553` заявлено: *«навчальні рядки, ознаки й прогнози всіх моделей у момент зрізу збігаються біт у біт»*. Однако в функции `check()` в `src/alerts/leakage.py:98` для обучающих строк вызывается:

  без аргумента `check_exact=True` (по умолчанию действует допуск float `atol=1e-8, rtol=1e-5`), в то время как для прогнозов в момент среза (строка 103) явно передаётся `check_exact=True`. - **Доказательство:** Запуск `scratch-gpro/stage7/test_bit_for_bit.py`: `pd.testing.assert_frame_equal(train_a, train_b, check_exact=True)` проходит без ошибок.
- **Последствие:** Код технически проверял приближённое равенство float, хотя заявлялось бинарное совпадение.
- **Что сделать и сколько стоит:** Дописать `check_exact=True` в `src/alerts/leakage.py:98`. Время: 1 минута.

## 4. Открытые вопросы

1. **Экспорт внешних диалогов ассистентов:** Сессии Claude Code и чаты планирования велись вне коммитов git. Для завершения пункта сдачи необходимо убедиться, что пользователь добавит файлы экспорта перед финальным дедлайном.
2. **Поведение `fetch_data.py` в окружении без git:** Если в чистом окружении нет утилиты `git`, `ensure_snapshot` не сможет склонировать `dataset_repo`. В рамках тестового стенда снимок уже склонирован в `dataset_repo/`, поэтому проверка хэша отрабатывает локально.
